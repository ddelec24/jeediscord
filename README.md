# JeeDiscord

Plugin Jeedom pour piloter et suivre Jeedom depuis Discord, basé sur [discord.js](https://discord.js.org/) v14 (API Discord v10).

- Jeedom 4.4 minimum, Debian 12 minimum
- Node.js installé et géré par le core Jeedom

La documentation utilisateur se trouve dans [docs/fr_FR/index.md](docs/fr_FR/index.md).
